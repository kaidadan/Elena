## Publish on GitHub Pages
1. Create a new GitHub repository, for example: `elena`
2. Upload all files from this folder to the repository root
3. Commit and push
4. In GitHub, open **Settings → Pages**
5. Under **Build and deployment**, set:
   - **Source**: Deploy from a branch
   - **Branch**: `main` / root
6. Save, then wait for GitHub Pages to publish your site

## Customization
- Edit page text inside each `.html` file
- Update styling in `assets/styles.css`
- Replace placeholder visuals with your own images by changing the `src` values in the HTML pages
